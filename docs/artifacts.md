# Illness Graphs and Exemplar Base

ECR-Agent can use the pretrained artifacts provided with MedEinst:

- [Illness Graphs](https://huggingface.co/datasets/zhui711/MedEinst-Illness-Graphs)
- [Exemplar Base](https://huggingface.co/datasets/zhui711/MedEinst-Exemplar-Base)

Download and extract the resources separately from the source repository. Configure the directories containing the extracted files, rather than the archive paths.

## Artifact layout

```text
artifacts/
├── golden_graphs_refined_1/
│   └── *_Refined_GG.json
└── memory_bank/
    ├── memory_bank.json
    └── embeddings.npy
```

The published Illness Graph collection contains **46 refined disease graphs**. Set `--refined-graph-dir` to the directory containing the `*_Refined_GG.json` files. If raw graphs are available, `--raw-graph-dir` can point to a directory containing `*_GG.json` files.

The Exemplar Base contains **700 case records** and an embedding array of shape **(700, 1536)**. Set `--memory-bank-dir` to the directory containing both `memory_bank.json` and `embeddings.npy`. The query embedding model should be compatible with the stored embeddings; matching dimensionality alone does not ensure identical embedding semantics.

## Online inference

After configuring model endpoints and downloading the benchmark dataset, an example command is:

```bash
python scripts/run_ecr_agent.py \
  --benchmark-set /path/to/test.jsonl \
  --refined-graph-dir /path/to/golden_graphs_refined_1 \
  --memory-bank-dir /path/to/memory_bank \
  --output-dir /path/to/online_results
```

## Artifacts generated by CGME

The Offline CGME command writes disease graphs to `cgme_output/golden_graphs/` and exemplar data to `cgme_output/memory_bank/` when using `--output-dir /path/to/cgme_output`.

An optional refinement step can produce refined graphs:

```bash
python scripts/refine_illness_graphs.py \
  --input-dir /path/to/cgme_output/golden_graphs \
  --output-dir /path/to/refined_graphs
```

The graph and memory files use the same schemas for Offline output and Online loading. See [Configuration](configuration.md) for path settings.
